### Hi, I'm 小磊丶同学

I focus on AI coding workflows and frontend engineering, turning complex, repetitive, and error-prone engineering problems into simple, reusable tools.

From managing AI tools in one place to creating full-stack projects that work out of the box, I aim to reduce setup, context switching, and repetitive work so developers can spend more time building.

Right now I care about:

- AI coding workflows, MCP, Skills, and model proxies
- Frontend engineering with React, Vue, Vite, and TypeScript
- Rust tools that make repetitive work lighter
- Clean templates, practical automation, and maintainable project structure
