### Hi, I'm 小磊丶同学

I like turning confusing, repetitive, and error-prone engineering problems into simple, reusable tools.

In programming, simplicity and elegance are worth chasing. When a concept feels unusually complicated, it often means we have not found the right way to break it down yet.

Right now I care about:

- AI coding workflows, MCP, and developer tooling
- Frontend engineering with React, Vue, Vite, and TypeScript
- Rust tools that make repetitive work lighter
- Clean templates, practical automation, and maintainable project structure
